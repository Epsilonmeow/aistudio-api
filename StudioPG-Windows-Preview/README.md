# 在 Windows 上用 SillyTavern 连接自己的 AI Studio

想保留喜欢的正文模型，只把剧情推进和填表交给本机？在插件里单独填一个地址就可以。也可以把酒馆正文接到本机，边生成边看回复。这个预览为同一个 AI Studio 网页提供 Gemini 和 OpenAI 两种文本接口。

**登录一次后，程序会保留专用浏览器资料。** 下次启动仍然打开同一个资料夹，浏览器会保存网站正常更新的登录信息。程序不靠定时发消息维持会话。遇到断网，程序会报错并保留资料。换电脑时，把软件解压到新电脑，再登录自己的账号就好。

**预览状态**　酒馆接口已经过离线联测。真实 Google 账号首次登录、当前线上网页能否顺利提交，以及跨过原先一两小时的掉登录时段，都还需要在独立账号上确认。Google 有时会限制由软件控制的浏览器登录；如果网页明确拒绝，请以网页提示为准。[Google 登录帮助](https://support.google.com/accounts/answer/7675428?hl=zh-Hans)

## 第一次安装

1. 准备一台装有 **Microsoft Edge 或 Google Chrome** 的 Windows 电脑。右键预览 ZIP，选择 **全部解压**，打开解压出来的文件夹。你会看到这份 README 和 **启动.cmd**。
2. 安装 **uv**，它负责准备 Python 和运行所需的软件。如果电脑已经有 uv，可跳过这步。打开开始菜单，搜索 **PowerShell**，打开后粘贴下方命令并按回车。完成后关闭 PowerShell。如果系统找不到 `winget`，可使用官方的其他 Windows 安装方式。[uv 安装说明](https://docs.astral.sh/uv/getting-started/installation/)

   ```powershell
   winget install --id=astral-sh.uv -e
   ```

3. 双击 **启动.cmd**。首次启动需要联网下载依赖，可能还会下载 Python 3.12。等窗口显示 **本机服务  http://127.0.0.1:8080**，保留这个窗口。
4. 点击启动窗口，按 **L**（字母 L），在打开的专用浏览器里登录**自己的 Google 账号**。确认能看到 AI Studio 的提问页面。整个流程不需要在开发者工具里复制 Cookie。
5. 回到启动窗口，按 **K**，本地连接密钥会复制到剪贴板。接下来把它粘贴到酒馆或插件的密码栏。

如果启动时提示 **无法使用 127.0.0.1:8080**，先看看是不是旧版服务仍在运行。新版会退出，旧服务可以照常使用。

## 接到酒馆

下面假设 SillyTavern 和本地服务装在同一台电脑上。

| 你要怎么用 | 在哪里设置 | 填入的地址 |
| --- | --- | --- |
| 正文使用 Gemini 接口 | 酒馆插头 → Chat Completion → Google AI Studio → 反向代理 | `http://127.0.0.1:8080` |
| 正文使用 OpenAI 兼容接口 | 酒馆插头 → Chat Completion → Custom (OpenAI-compatible) → API URL | `http://127.0.0.1:8080/v1` |
| 只让剧情推进、填表走本机 | 插件的「API 与连接」→ 关闭「使用主 API」→ API 基础 URL | `http://127.0.0.1:8080/v1` |

**代理密码或 API Key** 填刚才按 K 复制的值，每台电脑自己生成。连接并加载模型列表，选择 **ai-studio-current**。每次请求都会打开新的网页对话，这个名字代表新对话实际使用的模型。其他标签页临时选中的型号未必会沿用。插件如果有单独的剧情推进预设，记得保存后再选中。

你可以用一句很短的消息确认实际生成。开启酒馆或插件的 **Streaming（流式传输）** 后，回复会随网页可见正文逐段显示。消息会提交到 AI Studio 网页，使用专用窗口所登录账号的额度。

## 下次启动、断网和换机

- **关闭和重开**　在启动窗口按 **Ctrl+C** 退出。下次双击 **启动.cmd**。需要查看网页登录状态时按 L。
- **临时断网**　等网络恢复，查看网页仍然处于登录状态后，再发送下一条消息。已经提交到网页的请求不会自动补发，避免一次点击产生两次生成。
- **网页明确要求重新登录**　在专用窗口完成登录即可。本地程序无法延长 Google 已撤销的会话。
- **换电脑或分享**　只使用原始软件 ZIP。登录资料和本地连接密钥保存在当前 Windows 用户的 `%LOCALAPPDATA%\StudioPG-SinglePreview`。新机重新登录、按 K 取新密钥。角色卡、聊天和数据库插件由 SillyTavern 自己管理。

## 适用的请求

支持文本模型列表、普通文本和流式回复，一次处理一个请求。消息历史和系统说明会整理成网页可见的文本。温度、安全设置和最大输出长度以网页为准，客户端填写的 token 上限不会由本机精确执行。需要图片、工具调用、精确 token 计量或强制 JSON Schema 的插件，需要另选支持相应能力的接口。

这份预览提取了此前酒馆适配的文本接口设计，单账号后端使用普通浏览器的持久资料和可见网页控件。项目来源可见[上游项目](https://github.com/DeconstructedCube/aistudio-api)和[已公开的酒馆适配分支](https://github.com/Epsilonmeow/aistudio-api/tree/codex/windows-sillytavern)。
